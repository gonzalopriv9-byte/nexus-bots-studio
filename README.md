# Nexus Bots Studio

## Technical Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/gonzalopriv9-byte/nexus-bots-studio.git
   cd nexus-bots-studio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the application:
   ```bash
   npm start
   ```

4. For more complex setups, refer to the documentation in the repository.
